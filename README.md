## 🏗️ Arquitectura del Proyecto (MVVM)

El código fuente en `app/src/main/java/com/example/appmastermartini_grupo9/` sigue el patrón de diseño MVVM:

* `model/`: Clases de datos, entidades del dominio y DTOs.
* `repository/`: Capa de datos para abstracción y acceso a fuentes de información (simuladas o remotas).
* `viewmodel/`: ViewModels encargados de manejar el estado (`StateFlow`) y la lógica de presentación.
* `ui/`: Pantallas y componentes visuales desarrollados con Jetpack Compose y Material 3.
